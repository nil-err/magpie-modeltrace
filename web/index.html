ModelTrace

让一个模型凭第一反应写出一长串整数，再和 ModelTrace 的指纹库比对，看它最像库里的哪个模型。 用于回答「这个中转 / 路由组给的到底是不是它说的那个模型」。

连接

任何 OpenAI 兼容的 /v1/chat/completions 都可以：magpie 网关、官方 API、或第三方中转。 配置只存在这台浏览器的 localStorage 里，不会上传到任何地方。

浏览器直连要求网关允许本站来源（CORS）。magpie 需把本站 origin 填进 Settings → CORS origins；官方 API 一般不允许浏览器直连，请改用中转。
